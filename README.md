# phone-usage-analysis
My first Data Science project built with Python.

## project overview
Analyzed 7 days of personal smartphone usage data to understand app usage patterns and screen time habits.

## What I did
-Collect and cleaned daily phone usage data using Pandas
-Calculated total screen time and time spent on each app
-Created data visualizations:Pie chart for app distribution,Line chart for daily trends
-Identified peak usage days and average screen time

## Tools and Technologies
- **Language** : Python
- **Libraries** : Pandas,Matplotlib
- **Data Format** : CSV

-Average daily screen time : 9.48 hours
-Most used app : FaceBook
-Peak usage day : ThursDay
